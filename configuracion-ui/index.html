Túnel

Cómo se publica el servidor en internet para que Claude o ChatGPT puedan llegar a tu PC sin abrir puertos.

Modo

Opciones

Cloudflare Zero Trust → Redes → Túneles → tu túnel → Instalar conector.
Sin /mcp. Ejemplo: https://mcp.tudominio.com
HTTP/2 funciona en casi todas las redes. QUIC puede ser bloqueado por algunos routers.
Descarga la última versión desde GitHub cada vez que arranca el servidor.
Sin túnel, el servidor solo responde en esta PC. Si usas tu propio proxy, pon su dirección pública arriba.
Si cambia la dirección pública, tendrás que volver a autorizar el conector en Claude o ChatGPT.
